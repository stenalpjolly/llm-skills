# Drafting Migration Issues

This skill translates a Next.js architecture map into atomic, actionable migration tasks. 

## Rules
1. **One File, One Issue.** Do not bundle multiple components into a single issue unless they are tightly coupled sub-components.
2. **Separate Frontend and Backend.** React components must be tagged for Angular Material. Next.js API routes must be tagged for Python.
3. **Establish Dependencies.** If `LoginForm.jsx` imports `Button.jsx`, the issue for `LoginForm` MUST list `Button` as a dependency.
4. **Strict Formatting.** You must format every drafted issue exactly according to the template in `references/issue-template.md`.

## Workflow
1. Read the `architecture_map.json` generated by the `scanning-codebase` skill.
2. Group the files into logical Epics (e.g., "Authentication", "Dashboard").
3. Draft the issues using the reference template.
4. Save all drafted issues into a single file named `drafted_issues.json`.
