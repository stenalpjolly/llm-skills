# Generic Template Structure

When generating a scenario, use this structural flow and adapt the placeholders to the specific software domain:

Were you able to do the following
- [Core Action 1: e.g., Select the correct initial context/workspace]
- [Core Action 2: e.g., Create or configure the main entity]
- [Automated/Complex Action]: (e.g., Not every generated/calculated item might be right)
- [Manual Fallback]: e.g., Manually add or edit items
- [Support/Assistance]: e.g., Interact with support/helpers with proper context, was the assistance helpful for task completion, were you able to provide [links/logs/artifacts] to verify
- [Collaboration/Validation]: e.g., Were you able to share your [screen/workspace/output] and show the demo/results
- [Completion State]: e.g., Were you able to provide the details for submission/finalization
- I hope you didn't see [Restricted Element/Data], you are not supposed to see it. Only [Authorized Role] should see [Restricted Element/Data]
